# Getting help

PressTrace has no paid support. Help comes through the docs, GitHub Discussions and the issue tracker.

## Questions

Start with the [documentation](https://onwp.github.io/presstrace-wordpress-apm/). The [troubleshooting page](https://onwp.github.io/presstrace-wordpress-apm/app/troubleshooting) lists the start-up errors of the app and what fixes each one.

If the docs do not answer it, ask in [GitHub Discussions](https://github.com/onwp/presstrace-wordpress-apm/discussions). Questions asked there help the next person with the same problem.

## Bugs and feature requests

Open an [issue](https://github.com/onwp/presstrace-wordpress-apm/issues/new/choose) with the form for a bug or a feature. For a bug, include the PressTrace, WordPress and PHP versions, and the app log (`docker compose logs app`) if the app is involved. Remove site keys, passwords and personal data before you post.

## Security problems

Do not open a public issue. Report them privately as described in [SECURITY.md](SECURITY.md).
